# Publier les publicités dans Meta (Gestionnaire de publicités)

1. **Campagne** : Créer → objectif **Ventes** → pixel/catalogue Shopify de la boutique. Budget au niveau de la campagne (ex. 30 à 60 $/jour pour commencer).
2. **Ensembles de publicités** : un par angle (A1 à A6).
   - Lieu : **Canada → Québec** (province). Langue : **français**.
   - Âge : 25-65 ans. A1 à A5 : femmes en priorité ; A6 : tous les genres.
   - Placements : Advantage+ (automatiques).
3. **Publicités** : dans chaque ensemble, ajoutez les fichiers de l'angle (voir `tableau-statiques-angles.csv`).
   - Image 1:1 pour le fil ; Meta vous propose d'ajouter la version 9:16 (dossier `stories-9x16`) pour Stories et Reels.
   - Vidéos UGC (`videos-ugc`) : à placer dans A1 et A3.
   - Texte principal, titre, description : copiez-les depuis `textes-publicites.md` (même texte principal pour toutes les pubs d'un angle).
   - Bouton : **Magasiner**. Lien : celui indiqué dans le tableau.
4. **Avant de publier** : vérifiez que l'offre « 1 lot acheté = 1 lot offert » est bien active dans Shopify (réduction automatique jusqu'au 25 décembre) et que le site affiche les prix en $ CA.
5. **Lecture des résultats** : après ~1 000 impressions par pub, gardez les pubs au meilleur CTR ; ensuite jugez sur le coût par achat. Coupez les perdantes, dupliquez les gagnantes.

Règles : ne pas ajouter de nombre d'avis ni de « 406 avis » dans les pubs ; ne pas promettre de remise autre que l'offre réelle.
