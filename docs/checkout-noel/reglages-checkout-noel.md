# Checkout de Noël : Chaussettes Québécoise

Shopify admin → **Paramètres → Paiement (Checkout) → Personnaliser**

## 1. Images (Paramètres de marque → Logo / Bannière)
- **Logo** : `logo-noel-blanc.png` (blanc, fond transparent), position *Centré*, taille *Moyen*.
- **Bannière** (en-tête) : `banniere-noel-checkout.png`.

## 2. Couleurs (Paramètres de marque → Couleurs)
| Élément | Couleur |
|---|---|
| Arrière-plan principal (formulaire) | `#FFFFFF` |
| Arrière-plan récapitulatif de commande | `#FBF4EC` (crème) |
| Accent (liens, cases cochées, focus) | `#1F5C3A` (vert sapin) |
| Boutons principaux (« Payer maintenant ») | `#B3121F` (rouge Noël), texte `#FFFFFF` |
| Boutons au survol | `#7A0E17` |
| Erreurs | `#B3121F` |

## 3. Typographie
- Titres : **Playfair Display** (ou *Lora*)
- Texte : **Inter** (ou *Lato*)

## 4. Formes
- Coins des boutons et champs : *Arrondis* (petit rayon)

## 5. Texte festif (facultatif)
Dans **Paiement → Personnaliser → Contenu / Bloc texte** :
> 🎄 Offre des Fêtes : 1 pack acheté = 1 pack offert, appliquée automatiquement. Expédition sous 1 à 2 jours ouvrables avec suivi.

Cliquez sur **Enregistrer**. Après Noël, remettez la bannière et le logo habituels.
